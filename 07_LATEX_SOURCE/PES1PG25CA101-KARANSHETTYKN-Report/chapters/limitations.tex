\section{Current Challenges}

\textbf{Technical Challenges:} Key challenges identified during Phase-I include maintaining numerical stability for Mahalanobis OOD computation, ensuring reliable error prioritization under temporal distribution shift, handling high model confidence on shifted data, and stabilizing heuristic feedback-based signal weighting:

\begin{itemize}
\item Covariance Matrix Inversion in High Dimensions: Computing regularized Mahalanobis distance across 49 numerical features required careful Tikhonov regularization (eps = 1e-6) to prevent numerical instability arising from multi-collinear network telemetry attributes.
\item Inversion of Geometric OOD Utility Under Shift: In tabular network traffic, out-of-distribution instances frequently correspond to benign high-throughput data transfers rather than classifier errors, causing pure OOD detection to yield a near-zero error capture rate (0.03\% to 0.35\%).
\item Overconfidence in Uncalibrated Classifiers: Modern gradient boosted decision trees maintain high confidence scores on shifted data despite an error rate surge of 4.55x, complicating pure confidence thresholding.
\item Dynamic Weight Adaptation Stability: Preventing oscillation in heuristic feedback loops when audit batch sizes are small requires smoothing or learning-rate damping.
\end{itemize}
